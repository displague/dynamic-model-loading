# v0.42.0 - Phase-switched loading trades bytes for lower latency

Sixth completed delivery in the authorized four-to-eight course. The 40.671-second
CPU-first OPT-2.7B FP16 screen passes every frozen component gate. All checked
logits match dense streamed FP16 exactly, including both candidate warmups; all
48 scored tokens per condition agree under the same 4800 MiB allowance.

Dense prefill plus exact scalar-decode packets takes 2.545918 s versus 3.223919 s
for always-packet: 21.0303% less whole-episode time and 42.0176% less prefill call
time, while buying 26.1433% MORE outgoing bytes. The cost is explicit. Against
dense streaming, it saves 90.6293% of outgoing H2D and 63.2498% of episode time.
All three modes have the same sampled GPU peak: 4,763,783,168 B (about 4543 MiB).
