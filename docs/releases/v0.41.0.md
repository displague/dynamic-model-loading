# v0.41.0 - Longer prefixes separate prefill loss from decode savings

Fifth delivery, following the owner's continuation request. The 49.901-second
CPU-first OPT-2.7B FP16 screen uses 512-token prefixes and 16-token continuations.
All checked logits are exact, including warmups; 48 scored tokens per condition
match. Both controls fit 4800 MiB, peak sampled GPU 4,763,783,168 B (about 4543 MiB).

Prefill packets use 68.9268% of dense-stream outgoing bytes and 146.3295% of its
forward-call time: BOTH prefill gates fail. Decode uses 3.3287% of bytes and 21.3284%
of call time, passing both decode gates. Whole packet episodes save 92.5714% H2D
and 62.8169% wall (4.187751 s versus 11.262525 s), but this does not waive the prefill
failures. Stop uniform long-prefix expansion; preserve the phase distinction.
