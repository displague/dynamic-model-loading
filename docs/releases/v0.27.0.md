# v0.27.0 - A joint page field, and a preserved negative

Third of six authorized research deliveries. An **11.5-second CPU screen** tests
whether an observed precision page predicts signed decision effects on unobserved
pages. It implements a joint Gaussian field, not another per-layer FFN-error GP.
**Hspatial fails; stop this static-field candidate.**

One-probe diagnostic MSE: independent **.09131851**, field **.09127416**,
shuffled **.09095631**. Field improves only **0.049%**, misses the frozen10% bar,
and loses to shuffled geometry. Four probes worsen field MSE by0.966%.
Nominal90 coverage80.06% is descriptive, not a guarantee. Fit-only probe order
[4,1,24,34]; observed sites excluded from metrics.

Reuse96 fit positions/six documents and32 diagnostic positions/two documents
from v0.26. This is development-data screening, not independent confirmation,
accepted-token evidence or a physical loading-speed result.

[Krause et al.](https://jmlr.csail.mit.edu/papers/volume9/krause08a/krause08a.pdf),
with structured/independent decomposition inspired by
[spatial modeling](https://www.paulamoraga.com/book-spatial/bayesian-spatial-models.html).
Their methods are not newly invented here; variance reduction is not automatically
decision value of information.
