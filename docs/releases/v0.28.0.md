# v0.28.0 - Changing decision coordinates, not a recursive-loader win

Fourth of six authorized bounded releases. A **12.2-second CPU screen** separates
vector-coordinate representation from recursive Bayesian estimation.
**Hgeometry passes; Htemporal fails.**

Diagnostic MSE: static scalar **.09180881**, static vector **.08232945**,
recursive vector **.08119994**. Current-direction vector representation reduces
error **10.325%**, passing its frozen10% screen. Recursion adds only **1.372%**,
missing its independent10% gate. Scalar/vector fitted rho .002427/.189807.
Nominal90 coverage remains79.33%/79.54% for static/recursive vectors: not a safety
certificate. Only the passing geometry premise advances to a new short protocol.

Four causal rotating observations,31 unobserved sites scored per position.
Reuse96 fit and32 diagnostic positions from v0.26, only two diagnostic documents.
This is development screening, not independent confirmation, an online policy,
accepted-token improvement, physical traffic saving or larger-model access.
