# v0.1.0 - Reproducible FFN packing apparatus

This research prerelease establishes the reference apparatus for selective dense-FFN
experiments. It records a BF16 numerical failure and a passing, separate FP32 control.
It does not provide a weight pager or demonstrate inference speedup or memory savings.

Qwen2.5-1.5B-Instruct revision `989aa7980e4cf806f80c7fef2b1adb7bc71aa306`
was evaluated on an RTX 5080 Laptop GPU using PyTorch 2.10.0+cu130. The authored smoke
fixture contains 248 calibration tokens and 469 diagnostic input tokens across six
documents, yielding 463 next-token predictions. It is an apparatus check, not a
research quality benchmark.

Paired gate/up rows and down-projection columns are physically reordered together.
The harness preserves source, checkpoint, configuration, corpus, environment, layouts,
and flushed raw measurements. It reports reconstruction, next-token KL, perplexity,
top-1 agreement, dense timing/memory, and hypothetical selected weight volume. Tiny
real-architecture tests cover Qwen, Granite, and LFM2 FFN adapters; only Qwen's actual
pretrained checkpoint was evaluated.

All 84 local BF16 reconstruction checks passed, but 12 of 18 full-model layout checks
failed. Maximum relative logit L2 reached 0.02959 for random and 0.02468 for popularity
order, above the frozen 0.01 limit. Maximum mean KL reached 0.001528, above 0.001.
The failure correctly blocked every BF16 sparsity probe. Native order was exact.

A separate FP32 control passed unchanged tolerances: maximum relative logit L2 was
2.85e-6 and maximum mean KL approximately 5.68e-8. All 18 diagnostic configurations
completed. At 75% retention, popularity-based individual-neuron selection had relative
perplexity 1.0090; 32-neuron grouping raised it to 1.0959. This motivates packing
studies without claiming that the hindsight importance heuristic is optimal.

Validation at delivery: 22 tests passed, automated review completed, and archived
receipt hashes were verified. BF16 parameter storage was 3,087,428,608 bytes; FP32
storage was 6,174,857,216 bytes. Both gate/up projections and the masked down projection
still execute densely with the full model resident. Selection accounting does not
measure actual transfers or reduced residency.

The next experiments are a larger calibration/development sample, co-activation
packing, arithmetic-order diagnosis, and per-layer omission sensitivity. Predictor,
cache, transfer, and refinement feasibility remain open. This delivery contributes to
original stages 0-2; it does not close their full research gates.

This release is catalogued retrospectively on 2026-09-11. The initial implementation
was originally committed as `119cbbc67891d50a68755923324e4b927fb69ee9`; its message was
expanded with authorization while retaining the exact tree. The per-release note was
added during the later roadmap publication and is not presented as a pre-run record.
