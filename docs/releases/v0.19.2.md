# v0.19.2 — Restore Claude Write and distinguish rejected edits

The local launcher requested Read/Edit/Write, but Claude Code2.1.260 bare mode
advertised only Read/Edit. Replace bare mode with safe mode to restore Write while
preserving restricted workspace access, customization isolation, interactive
permissions, manual compaction and the existing context/output budgets.

Edit was already available: the reported session contains seven successful Edit
results and25 argument rejections (13 ambiguous matches, seven missing matches,
four attempts to create existing files and one malformed JSON call). The prompt
now explains exact-match editing, creation versus overwrite and bounded recovery.
This is guidance, not an enforced retry limiter or proof of reliable model editing.

Both frozen native file-tool cases pass. Safe mode advertises all three requested
tools and successfully creates, reads, edits and overwrites generated files;
prescribed invalid edits leave bytes unchanged. Four corrected context checks also
pass, retaining the earlier failed harness attempt. The automatic negative control
reproduces the thrashing warning; manual mode completes its reads and `/compact`.
These are scripted loopback checks, without new model inference or GPU measurements.

Independent review and296 full-suite tests in each retained environment support
publication. All276 archive members restore with exact hashes; aggregated ledgers
and file-tool verdicts reproduce. Private source/conversation content is excluded.
