# v0.2.0 - Packing pilot and BF16 arithmetic diagnosis

This research prerelease tests whether calibration-only co-activation grouping
preserves more useful FFN sparsity than simple popularity ordering. The tested
heuristic loses in all four grouped settings. The result narrows this packing
hypothesis without rejecting other grouping methods or establishing a paging runtime.

The FP32 Qwen2.5-1.5B-Instruct checkpoint and PyTorch 2.10.0+cu130 baseline are unchanged.
Calibration uses 80 WikiText training articles (20,480 tokens); diagnostics use 16
validation articles (4,096 inputs, 4,080 next-token predictions). Each document is a
256-token prefix. The test split was neither downloaded nor scored. Corpus and
checkpoint revisions, source snapshots, reservoir ordinals, layouts, and raw receipts
are preserved.

The new grouping heuristic normalizes neuron importance profiles from a uniform
512-token reservoir, projects them onto 64 random-sign directions, and recursively
bisects them into capacity-constrained 32-neuron groups. The same physical order is
reused at widths 1, 32, and 128, retaining 50% and 75% of groups. All selectors use
already-computed activations and are hindsight diagnostics.

All 112 local reconstruction and 64 full-model layout checks passed the frozen gates;
maximum full-model relative logit L2 was 2.174e-6. All 24 configurations completed,
preserving 384 per-document measurements. At width 32 and 75% retention, popularity
packing gives KL 0.154117, relative perplexity 1.1287, and 83.43% top-1 agreement;
co-activation gives KL 0.179357, relative perplexity 1.1676, and 81.13% agreement.
Individual-neuron popularity selection at the same retained fraction gives KL
0.002173 and relative perplexity 1.0001, exposing the grouping penalty.

The predeclared paired comparison, co-activation minus popularity KL, is +0.02524
with exploratory 95% whole-document bootstrap interval [+0.01648, +0.03468]
(2,000 replicates, seed 1729). Popularity also wins on KL, perplexity, and top-1 in
every width-32/128, retention-50%/75% comparison. No setting or tolerance was retuned.

Five arithmetic controls on all six smoke documents preserve the original BF16
failure. Disabling reduced-precision reduction, computing the down projection in
FP32, and computing the entire FFN in FP32 before BF16 output all fail the original
permutation gate. Restoring original down-projection neuron order is exactly equal
to the BF16 reference, but requires inverse gathers of activations and weights.
It isolates an ordering effect in this control, not an efficient execution policy.

Review corrected false article boundaries caused by inline table/equation records.
A fresh corpus build remained byte-identical, so existing pilot measurements were
retained. Review also added missing precision token/permutation receipts; a fresh
diagnostic run reproduced all 60 rows and its summary byte for byte. Both originals,
corrections, and audits remain archived. At delivery, 31 tests passed, final review
found no blocking issues, and all 56 archived file hashes matched staged Git blobs.

The full model remains resident; masked dense multiplication measures no actual
sparse speedup, cache behavior, or saved transfers. This is a small English Wikipedia
development slice, not a multi-domain or confirmatory quality result. Next, measure
per-layer omission and cross-layer interactions before changing the packing method.
