# v0.3.0 - Per-layer omission and interaction study

This research prerelease completes the missing per-layer omission experiment from
Stage 1 of the original plan. Omission sensitivity is distributed across the model
on this development slice: the four largest individual-layer KL values contribute
only 20.82% of their sum under popularity packing and 19.57% under co-activation.
The result does not identify a few dominant layers whose protection would remove
most of the grouping penalty, and no layer allocation was fitted after scoring.

The protocol and implementation were pushed as `45bfecb` before measurement. The
study freezes the Qwen2.5-1.5B-Instruct checkpoint, 80-article calibration corpus,
16-article WikiText development slice, token IDs, and two learned layouts from
v0.2.0. Execution remains FP32 on the RTX 5080 Laptop GPU with Python 3.14.3 and
PyTorch 2.10.0+cu130. PyTorch 2.12 validation is tracked separately to avoid silently
mixing environments.

All 56 local reconstruction and 32 full-model layout checks passed the original
tolerances, with maximum relative logit L2 2.174e-6. All 66 declared conditions
completed: each of 28 FFNs separately, all FFNs together, and four fixed contiguous
seven-layer blocks for popularity and co-activation layouts. Each masks groups of
32 neurons at 75% retention, evaluated across 4,080 next-token predictions. The raw
ledger preserves 1,056 individual document measurements before aggregation.

Popularity's single-layer KL values sum to 0.135793, versus joint-layer KL 0.154117
(ratio 1.1349). Co-activation's sum is 0.148994, versus joint KL 0.179357
(ratio 1.2038). These are descriptive comparisons, not additive error decompositions.
Every single-layer PPL change is below 1% on this slice, while jointly masking all
layers increases PPL by 12.87% for popularity and 16.76% for co-activation. No new
quality-equivalence threshold is adopted from these observations.

Co-activation improves single-layer KL at layers 2, 4, 5, and 25, but has higher KL in
the other 24 layers and all four fixed blocks. Preserve the metric exception: for block
14-20, co-activation has lower relative PPL (1.015668 versus 1.020144) despite higher
KL (0.031090 versus 0.026509). All 32 per-document all-layer controls reproduce every
parent quality metric exactly; the paired KL difference remains +0.02524 with the
same exploratory interval [+0.01648, +0.03468]. This repeated use of the same data
is a reproducibility check, not independent evidence.

Unmasked layers are charged at full hypothetical volume. Single-layer masking retains
99.1071% of whole-model FFN weights, a seven-layer block retains 93.75%, and all-layer
masking retains 75%. These fractions exclude non-FFN weights and describe selection
accounting, not measured transfers or reduced residency. Dense masked operations
still execute with the complete model resident; no inference speedup is claimed.

Before measurement, review corrected unanchored parent metadata, unverified parent
control metrics, incomplete plot validation, and missing interruption receipts. All
38 tests pass; final implementation review found no blocking issues. Complete raw
condition coverage, aggregate recomputation, source/input hashes, and same-data
control reproduction were checked. The standalone PNG/SVG figure was visually
inspected, and exact measurement sources and inputs are archived.

This delivery closes issue #7. The multi-domain held-out Stage 1 gate remains open,
as do practical BF16 execution, ReLU controls, causal prediction, real RAM-to-VRAM
movement, and corrective refinement. The next bounded task is Stage 2 transfer
amplification and cache-trace accounting, retaining the observed quality cost of each
selection policy. The repository now keeps the original stage plan, GitHub milestones
and issues, detailed release sources, and annotated tags alongside the experiments.
