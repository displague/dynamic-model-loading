# v0.19.1 — Explicit Claude context recovery for the local server

Claude Code 2.1.260 subtracts a fixed 13000-token compaction reserve after the
configured output budget. For this launcher's 18432-token context and 2048-token
output allowance, proactive compaction starts at 3384 tokens. The reported session
compacted six times without any Read calls; small summaries soon crossed the same
threshold again. The percentage override cannot raise that limit.

The launcher now defaults to child-only manual compaction, preserves `/compact`,
bounds Read output and keeps the true server capacity. Restart Claude through
`local.ps1 claude`; the model server can remain running. Check `/context`, use
`/compact` around 8000 tokens, and save a concise handoff/start fresh if needed.
This is an explicit workaround, not a repaired automatic controller.

The installed CLI passes four declared scripted-loopback checks in the final
attempt: automatic mode emits two boundaries around 6000 reported tokens; manual
mode completes five successful reads without auto-compaction; oversized Read output
is explicitly trimmed before a successful targeted read; and manual `/compact`
works. Both earlier failed attempts remain in the archive. These checks use
synthetic API responses and token counts, with no model inference or GPU timing.
The full rapid-refill breaker and live-model summary quality are not qualified.

Independent review and 295 full-suite tests in each retained PyTorch environment
support the delivery. All 230 raw archive members restore with exact hashes and
all three result ledgers match byte-for-byte. Private project/conversation content
is excluded. Archive SHA256:
`2387c1a1c033d3cfa1caaf53b3391a14b6a0f105607a1d967989dec73f8083c8`.

Complete [#33](https://github.com/displague/dynamic-model-loading/issues/33) as a
bounded client workaround. Keep [#27](https://github.com/displague/dynamic-model-loading/issues/27)
and the broader milestone open. No model, placement, precision, native runtime,
upstream PR or optimization experiment changes in this patch.
