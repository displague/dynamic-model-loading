# v0.19.0 - Run the stock configuration locally; Claude edits, Codex remains limited

The measured configuration is now available through a local PowerShell launcher,
with named stock controls and isolated coding-client settings. **No native rebuild,
runtime patch, API proxy or new model is required.** The installed stock b10919
binary and pinned Qwen32B target/0.5B draft are reused.

From the main Windows checkout, run `./local.ps1 serve`, then in another terminal
`./local.ps1 claude -Workspace C:\path\to\project`. Use `-Profile stock-speculative`,
`whole-layer` or `target-only` to compare configurations, stopping the previous
server first. `-PrintCommand` prints the complete native argv and child environment.
The [interactive guide](https://github.com/displague/dynamic-model-loading/blob/v0.19.0/docs/local-interactive.md)
documents the exact profiles, binary location, endpoint URLs and client scope.
