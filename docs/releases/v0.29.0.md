# v0.29.0 - Decision-value acquisition earns a physical test

Fifth of six authorized releases. A **26.6-second CPU screen** nominates the
decision-risk policy at the same17-page budget. Diagnostic pair errors:
**risk0/32, fixed2/32, contribution2/32, independent-risk3/32**.
Risk repairs all seven base pair errors without adding new errors.
**Hrisk passes; Hcontribution fails.** No unseen-page oracle or recurrence is used.

Projection/conditioning equivalence passes within1.111e-15. The higher-order
quadrature audit checks every available action on both diagnostic risk paths,
maximum difference1.520e-11. These qualify an algebraic shortcut and numerical
implementation, not calibrated probabilities. The Gaussian model undercovered
previously; the result is a small decision-ranking screen win.

This is a **binary base-pair proxy**, not full-vocabulary argmax or accepted draft
tokens. Reuse96 fit positions/six documents and32 diagnostic positions/two documents
from v0.26; no independent-confirmation or physical speedup claim.
